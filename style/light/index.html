About light icons

What this style means

Light icons are light-weight icons, typically a 300-weight cut, for interfaces that need a softer touch. IconStash classifies icons by style across all 28 indexed libraries, so you can hold the weight constant and compare how different design teams solve the same icon.

When to use them. Light icons suit editorial layouts, premium products, and generous spacing. At 12–16px beside small text they become hard to scan — use a regular or bold weight there instead.

Every icon below links to a page with the full SVG source, a live preview you can recolour and resize, PNG export at six sizes, and a ready-to-paste React snippet.

Frequently asked questions

What are light icons?

When should I use light icons?

Light icons suit editorial layouts, premium products, and generous spacing. At 12–16px beside small text they become hard to scan — use a regular or bold weight there instead.

Which libraries include light icons?

On IconStash the strongest coverage comes from Material Symbols Light (9,581), Phosphor Icons (1,542), Fluent UI Icons (282). Open any library hub to see its full style range alongside install instructions.

Can I export light icons as PNG?

Yes. Every icon on IconStash exports to PNG at 16, 32, 64, 128, 256, or 512 pixels, generated in the browser from the original vector so it stays crisp at any size. You can also copy the raw SVG, export a React component, or build an SVG sprite.

Are these light icons free for commercial use?

The libraries indexed here are MIT, Apache 2.0, CC BY 4.0, or CC0 licensed, all of which permit commercial use. CC BY sets such as Solar Icons require attribution — check the license shown on each icon page if you cannot provide credit.
