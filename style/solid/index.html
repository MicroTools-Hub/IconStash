About solid icons

What this style means

Solid icons are fully filled icons with no internal stroke, carrying the most visual weight of any style. IconStash classifies icons by style across all 28 indexed libraries, so you can hold the weight constant and compare how different design teams solve the same icon.

When to use them. Solid icons are the standard choice for active navigation, selected filters, and primary actions. Used everywhere they make an interface feel heavy, so most products pair them with an outline set for default state.

Every icon below links to a page with the full SVG source, a live preview you can recolour and resize, PNG export at six sizes, and a ready-to-paste React snippet.
