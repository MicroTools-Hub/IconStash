Design & UX integration

Aesthetic characteristics

Globus is a brand mark, not a UI glyph. Simple Icons maintains official-colour SVG logos for thousands of products on a flat 24x24 grid, released under CC0. Because these are brand assets, they belong in tech stacks, README files and "built with" sections rather than in interface chrome.

UX best practices

In booking, fleet and logistics interfaces, use the Globus icon as a supporting glyph beside a text label. Mode-of-transport shapes are genuinely ambiguous across regions — a "train" glyph is drawn differently in Europe, Japan and North America — so never let the icon carry the meaning on its own.
