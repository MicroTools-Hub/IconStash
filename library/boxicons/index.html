About Boxicons

What Boxicons is

Boxicons is a long-running free icon pack by Atisa, with 3,389 icons across three families: Regular (outline), Solid (filled), and Logos. The logo set is a significant part of the appeal — hundreds of brand marks maintained alongside the UI icons.

The Regular and Solid families mirror each other, so an icon's outline and filled forms have the same optical footprint. The set is drawn on a 24×24 grid with a slightly heavier, rounder construction than the minimal outline libraries, which makes it read clearly even at small sizes.

IconStash indexes the complete Boxicons collection. You can search it alongside 27 other libraries, preview any icon at any size and colour, and export SVG, PNG, React JSX, Vue, CSS, or an SVG sprite without installing a package or creating an account.

Install and use Boxicons

React

npm install boxicons

The official package ships each icon as a tree-shakeable component, so bundlers only include the icons you actually import. Open any Boxicons icon on IconStash and the Code tab shows that icon's exact import statement and JSX.

Plain SVG and other frameworks

You do not have to install anything. Every Boxicons page lets you copy the raw SVG markup and paste it inline, which avoids a dependency entirely and gives you full control over colour, size, and stroke width.

IconStash also exports PNG at six sizes, Vue and CSS snippets, and SVG sprites — all generated in the browser from the original vector.

When to choose Boxicons

Good fit

Websites and apps that need UI icons and brand logos from one package — particularly portfolios, link-in-bio pages, tech stack sections, and footers.

Consider alternatives

For pure brand logos with a cleaner license, Simple Icons is CC0 and has 3,714 marks. For UI icons alone, Remix Icon and Tabler are more consistent.

Licensing

MIT for the icon set. Brand logos are trademarks of their respective owners — using them to represent the brand is generally fine, but do not use them to imply endorsement.

Frequently asked questions

What is Boxicons?

Boxicons is a long-running free icon pack by Atisa, with 3,389 icons across three families: Regular (outline), Solid (filled), and Logos. The logo set is a significant part of the appeal — hundreds of brand marks maintained alongside the UI icons.

Is Boxicons free for commercial use?

Yes. Boxicons is released under the MIT license, which permits unrestricted commercial use, modification, and distribution. No attribution is required, though it is appreciated. This makes Boxicons one of the safest icon libraries to use in commercial SaaS products, client work, and proprietary applications.

How do I use Boxicons icons in React?

Install the package with npm install boxicons, then import icons as components. Every Boxicons page on IconStash shows the exact import statement and usage snippet for that specific icon in the Code tab, so you can copy working code without checking the docs. Tree-shakeable packages mean your bundler only includes the icons you actually import.

Can I download Boxicons icons as PNG?

Yes. Open any Boxicons icon on IconStash and use the Download PNG button to export at 16, 32, 64, 128, 256, or 512 pixels. The PNG is generated client-side from the original vector, so it stays crisp at every size. You can also copy the raw SVG markup, export a React component, or build an SVG sprite without installing anything.

Does Boxicons include brand logos?

Yes — the Logos family contains hundreds of brand marks maintained alongside the Regular and Solid UI icon sets. It is convenient for tech stack sections, footers, and social links. Remember that brand logos remain trademarks of their owners regardless of the icon license.

What is the difference between Boxicons Regular and Solid?

Regular is the outline family and Solid is the filled family. They are drawn to the same optical footprint, so toggling between them for hover or active state does not shift your layout. Logos is a third, separate family of brand marks with a different visual treatment.
