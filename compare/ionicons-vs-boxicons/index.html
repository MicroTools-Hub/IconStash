Ionicons vs Boxicons

Ionicons and Boxicons are two of the most widely used open-source icon sets. Both are free, both ship framework packages, and both will look perfectly reasonable in a product UI — which is exactly why the choice is annoying. This page puts the two side by side using the actual artwork and the real numbers.

The short answer

  • Boxicons is the broader set: 3,389 icons against 2,607 in Ionicons — roughly 30% more coverage, which matters most if you build interfaces that need unusual glyphs.
  • Ionicons gives you more visual range: 3 variants per concept (outline, filled and sharp), where Boxicons ships 3.
  • Both are MIT, so licensing is not a deciding factor here.

Which one should you choose?

Pick Ionicons when

Mobile and hybrid apps, cross-platform products, and interfaces that want three clear icon variants from one consistent source.

Consider otherwise if: For a more modern, minimal aesthetic, Lucide and Heroicons are the current defaults. Material Design Icons offers five themes if you need more range.

Pick Boxicons when

Websites and apps that need UI icons and brand logos from one package — particularly portfolios, link-in-bio pages, tech stack sections, and footers.

Consider otherwise if: For pure brand logos with a cleaner license, Simple Icons is CC0 and has 3,714 marks. For UI icons alone, Remix Icon and Tabler are more consistent.

Coverage

Ionicons contains 2,607 icons and Boxicons contains 3,389. Ionicons was built for the Ionic Framework and has been refined since 2013, which makes it one of the longest-maintained icon sets here. The 2,607 icons ship in three variants — Outline, Filled, and Sharp — each drawn on a 24×24 grid.

Boxicons is a long-running free icon pack by Atisa, with 3,389 icons across three families: Regular (outline), Solid (filled), and Logos. The logo set is a significant part of the appeal — hundreds of brand marks maintained alongside the UI icons.

Frequently asked questions

Which has more icons, Ionicons or Boxicons?

Ionicons has 2,607 icons and Boxicons has 3,389. Boxicons is larger by about 30%. Raw count is not the whole story though — a 20,000-icon set with many near-duplicate variants can be slower to search than a tightly edited 2,000-icon set.

Can I mix Ionicons and Boxicons in one interface?

You can, but it usually looks wrong. Each library draws to its own grid and stroke weight — Ionicons uses 24×24 and Boxicons uses 24×24 — so icons from both sit slightly differently next to each other. If you must mix them, keep each library to a distinct area of the interface rather than interleaving them in the same toolbar.

What licenses do Ionicons and Boxicons use?

Ionicons is MIT: Commercial use, modification and redistribution with no attribution required. Boxicons is MIT: Commercial use, modification and redistribution with no attribution required. Neither requires payment, but attribution rules differ, so check before shipping in a product where credit is inconvenient.

Do Ionicons and Boxicons include filled and outline versions?

Ionicons offers outline, filled and sharp; Boxicons offers regular, solid and logos. If you need to express selected and unselected states with the same glyph, the library with more variants saves you from importing a second set.

Which is better for small sizes like 16px?

At 16px, stroke weight and counter size matter more than coverage. Ionicons draws on a 24×24 grid and Boxicons on 24×24. Libraries that redraw per size rather than scaling — such as Fluent UI — generally hold up best. The reliable test is to preview both at your actual render size, which you can do on any icon page on IconStash.
