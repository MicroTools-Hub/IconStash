About Remix Icon

What Remix is

Remix Icon is a neutral-style system icon set maintained by Remix Design, organised across 25 categories. Its 3,244 icons are drawn on a 24×24 grid with a 1.5px stroke — noticeably lighter than the 2px default of Lucide or Tabler, which gives the set a more refined, technical feel.

Nearly every icon ships in both line and fill variants from the same package, so indicating selected state never requires a second library. The neutral styling is deliberate: Remix is designed to sit inside an existing design system rather than impose a look of its own.

IconStash indexes the complete Remix Icon collection. You can search it alongside 27 other libraries, preview any icon at any size and colour, and export SVG, PNG, React JSX, Vue, CSS, or an SVG sprite without installing a package or creating an account.

Install and use Remix

React

npm install remixicon

The official package ships each icon as a tree-shakeable component, so bundlers only include the icons you actually import. Open any Remix icon on IconStash and the Code tab shows that icon's exact import statement and JSX.

Plain SVG and other frameworks

You do not have to install anything. Every Remix page lets you copy the raw SVG markup and paste it inline, which avoids a dependency entirely and gives you full control over colour, size, and stroke width.

IconStash also exports PNG at six sizes, Vue and CSS snippets, and SVG sprites — all generated in the browser from the original vector.

When to choose Remix

Good fit

Products that already have a strong visual identity and need icons that adapt to it. The lighter stroke and neutral construction make Remix easy to pair with custom typography and colour systems.

Consider alternatives

If you want a heavier, more characterful outline, Lucide and Tabler read bolder. For more than two variants per icon, Phosphor and Solar go further.

Frequently asked questions

What is Remix Icon?

Remix Icon is a neutral-style system icon set maintained by Remix Design, organised across 25 categories. Its 3,244 icons are drawn on a 24×24 grid with a 1.5px stroke — noticeably lighter than the 2px default of Lucide or Tabler, which gives the set a more refined, technical feel.

Is Remix Icon free for commercial use?

Yes. Remix Icon is released under Apache 2.0, which permits commercial use, modification, and distribution and includes an express patent grant from the licensor. Attribution is not required for ordinary use, but you should not use the icons in a way that implies the licensor endorses your product.

How do I use Remix icons in React?

Install the package with npm install remixicon, then import icons as components. Every Remix page on IconStash shows the exact import statement and usage snippet for that specific icon in the Code tab, so you can copy working code without checking the docs. Tree-shakeable packages mean your bundler only includes the icons you actually import.

Can I download Remix icons as PNG?

Yes. Open any Remix icon on IconStash and use the Download PNG button to export at 16, 32, 64, 128, 256, or 512 pixels. The PNG is generated client-side from the original vector, so it stays crisp at every size. You can also copy the raw SVG markup, export a React component, or build an SVG sprite without installing anything.

Do Remix icons come in filled variants?

Yes. Almost every icon in the set has both a line and a fill version shipped in the same package, which makes it straightforward to show active states. On IconStash both variants are indexed, so searching a concept returns the line and fill forms side by side.

What stroke weight does Remix Icon use?

Remix uses a 1.5px stroke on a 24×24 grid, lighter than the 2px used by most outline libraries. That makes the icons feel more precise at small sizes but slightly more delicate at display sizes — if you plan to render icons above 48px, consider a heavier set or increase the stroke on export.
