Lucide vs Boxicons

Lucide Icons and Boxicons are two of the most widely used open-source icon sets. Both are free, both ship framework packages, and both will look perfectly reasonable in a product UI — which is exactly why the choice is annoying. This page puts the two side by side using the actual artwork and the real numbers.

The short answer

  • Boxicons is the broader set: 3,389 icons against 1,979 in Lucide Icons — roughly 71% more coverage, which matters most if you build interfaces that need unusual glyphs.
  • Boxicons gives you more visual range: 3 variants per concept (regular, solid and logos), where Lucide Icons ships 1.
  • Both are ISC, so licensing is not a deciding factor here.

Which one should you choose?

Pick Lucide Icons when

SaaS dashboards, developer tools, documentation sites, and any product that wants a calm, neutral, geometric icon language. Lucide is particularly strong in dense interfaces because its uniform stroke weight stays legible at 16px and 20px.

Consider otherwise if: If you need multiple weights from one library, Phosphor offers six. If you need filled icons, IconPark Solid or Material Design Icons are better choices, since Lucide is outline-only.

Pick Boxicons when

Websites and apps that need UI icons and brand logos from one package — particularly portfolios, link-in-bio pages, tech stack sections, and footers.

Consider otherwise if: For pure brand logos with a cleaner license, Simple Icons is CC0 and has 3,714 marks. For UI icons alone, Remix Icon and Tabler are more consistent.

Coverage

Lucide Icons contains 1,979 icons and Boxicons contains 3,389. Lucide began as a fork of Feather Icons when Feather's release cadence slowed and community pull requests began to pile up. Rather than let the project stall, contributors created Lucide with an explicit commitment to community governance and regular releases. It has since grown well past its parent: 1,979 icons against Feather's 286.

Boxicons is a long-running free icon pack by Atisa, with 3,389 icons across three families: Regular (outline), Solid (filled), and Logos. The logo set is a significant part of the appeal — hundreds of brand marks maintained alongside the UI icons.

Licensing

Lucide Icons is released under ISC. Functionally equivalent to MIT — no attribution required.

Boxicons is released under MIT. Commercial use, modification and redistribution with no attribution required.

Frequently asked questions

Is Lucide or Boxicons better for React projects?

Both have first-party React packages: lucide-react and boxicons. Lucide has the smaller catalogue, so for a React app the practical difference is coverage and visual style rather than integration effort. Both tree-shake, so bundle size tracks the number of icons you import, not the size of the library.

Which has more icons, Lucide or Boxicons?

Lucide Icons has 1,979 icons and Boxicons has 3,389. Boxicons is larger by about 71%. Raw count is not the whole story though — a 20,000-icon set with many near-duplicate variants can be slower to search than a tightly edited 2,000-icon set.

Can I mix Lucide and Boxicons in one interface?

You can, but it usually looks wrong. Each library draws to its own grid and stroke weight — Lucide uses 24×24 and Boxicons uses 24×24 — so icons from both sit slightly differently next to each other. If you must mix them, keep each library to a distinct area of the interface rather than interleaving them in the same toolbar.

What licenses do Lucide and Boxicons use?

Lucide Icons is ISC: Functionally equivalent to MIT — no attribution required. Boxicons is MIT: Commercial use, modification and redistribution with no attribution required. Neither requires payment, but attribution rules differ, so check before shipping in a product where credit is inconvenient.

Do Lucide and Boxicons include filled and outline versions?

Lucide Icons offers outline only; Boxicons offers regular, solid and logos. If you need to express selected and unselected states with the same glyph, the library with more variants saves you from importing a second set.

Which is better for small sizes like 16px?

At 16px, stroke weight and counter size matter more than coverage. Lucide draws on a 24×24 grid and Boxicons on 24×24. Libraries that redraw per size rather than scaling — such as Fluent UI — generally hold up best. The reliable test is to preview both at your actual render size, which you can do on any icon page on IconStash.
