Notable, Citable Facts

  • Lucide (1,979) has ~6.9× more icons than Feather (286), the project it forked from.
  • Fluent UI Icons is ~70× larger than Feather.
  • Just 4 libraries (Fluent, Material Symbols, Material Symbols Light, Material Design) account for 51% of all icons.
  • Google alone contributes 48,517 icons across three Material families.
  • 17 of 28 libraries are MIT-licensed — the single most common license by library count.
  • Simple Icons (3,714) is the only fully public-domain (CC0) set.

Methodology

Every figure on this page comes from a direct programmatic count of the icon files in each library's indexed release — not from marketing claims or upstream READMEs. The snapshot was generated on 2026-05-05 and the machine-readable source is published at /data/index.json.

Icon counts reflect distinct SVG glyphs in the version listed. Where a library ships multiple weights or styles of the same concept (for example Phosphor's six weights), each distinct exported file is counted once. License classifications follow each library's published LICENSE file at the indexed version. Solar Icons is classified as CC BY 4.0 (attribution requested); all other counts fall under MIT, Apache 2.0, ISC, or CC0.
