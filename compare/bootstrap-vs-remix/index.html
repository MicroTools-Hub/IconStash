Bootstrap vs Remix

Bootstrap Icons and Remix Icon are two of the most widely used open-source icon sets. Both are free, both ship framework packages, and both will look perfectly reasonable in a product UI — which is exactly why the choice is annoying. This page puts the two side by side using the actual artwork and the real numbers.

The short answer

  • Remix Icon is the broader set: 3,244 icons against 2,090 in Bootstrap Icons — roughly 55% more coverage, which matters most if you build interfaces that need unusual glyphs.
  • Bootstrap Icons gives you more visual range: 3 variants per concept (outline, filled and more), where Remix Icon ships 2.
  • Both are MIT, so licensing is not a deciding factor here.

Which one should you choose?

Pick Bootstrap Icons when

Bootstrap-based projects, admin templates, and compact interfaces where icons sit next to 14px text and need to hold their own at 16px.

Consider otherwise if: If you need strict visual consistency, the mixed fill and stroke treatment can look uneven next to Lucide or Feather. For a larger set with similar small-size optimisation, compare Octicons.

Pick Remix Icon when

Products that already have a strong visual identity and need icons that adapt to it. The lighter stroke and neutral construction make Remix easy to pair with custom typography and colour systems.

Consider otherwise if: If you want a heavier, more characterful outline, Lucide and Tabler read bolder. For more than two variants per icon, Phosphor and Solar go further.

Coverage

Bootstrap Icons contains 2,090 icons and Remix Icon contains 3,244. Bootstrap Icons is the official icon set for the Bootstrap framework, built by the Bootstrap team. The 2,090 icons are drawn on a 16×16 grid — tighter than the 24×24 used by most libraries — which makes them pair naturally with Bootstrap's default typography and compact control sizing.

Remix Icon is a neutral-style system icon set maintained by Remix Design, organised across 25 categories. Its 3,244 icons are drawn on a 24×24 grid with a 1.5px stroke — noticeably lighter than the 2px default of Lucide or Tabler, which gives the set a more refined, technical feel.

Licensing

Bootstrap Icons is released under MIT. Commercial use, modification and redistribution with no attribution required.

Remix Icon is released under Apache 2.0. No attribution required, but carries an explicit patent grant and requires notice for modified files.

Frequently asked questions

Which has more icons, Bootstrap or Remix?

Bootstrap Icons has 2,090 icons and Remix Icon has 3,244. Remix Icon is larger by about 55%. Raw count is not the whole story though — a 20,000-icon set with many near-duplicate variants can be slower to search than a tightly edited 2,000-icon set.

Can I mix Bootstrap and Remix in one interface?

You can, but it usually looks wrong. Each library draws to its own grid and stroke weight — Bootstrap uses 16×16 and Remix uses 24×24 — so icons from both sit slightly differently next to each other. If you must mix them, keep each library to a distinct area of the interface rather than interleaving them in the same toolbar.

What licenses do Bootstrap and Remix use?

Bootstrap Icons is MIT: Commercial use, modification and redistribution with no attribution required. Remix Icon is Apache 2.0: No attribution required, but carries an explicit patent grant and requires notice for modified files. Neither requires payment, but attribution rules differ, so check before shipping in a product where credit is inconvenient.

Do Bootstrap and Remix include filled and outline versions?

Bootstrap Icons offers outline, filled and more; Remix Icon offers line and fill. If you need to express selected and unselected states with the same glyph, the library with more variants saves you from importing a second set.

Which is better for small sizes like 16px?

At 16px, stroke weight and counter size matter more than coverage. Bootstrap draws on a 16×16 grid and Remix on 24×24. Libraries that redraw per size rather than scaling — such as Fluent UI — generally hold up best. The reliable test is to preview both at your actual render size, which you can do on any icon page on IconStash.
