Phosphor vs Iconoir

Phosphor Icons and Iconoir are two of the most widely used open-source icon sets. Both are free, both ship framework packages, and both will look perfectly reasonable in a product UI — which is exactly why the choice is annoying. This page puts the two side by side using the actual artwork and the real numbers.

The short answer

  • Phosphor Icons is the broader set: 9,198 icons against 2,020 in Iconoir — roughly 355% more coverage, which matters most if you build interfaces that need unusual glyphs.
  • Phosphor Icons gives you more visual range: 6 variants per concept (thin, light, regular, bold, fill and duotone), where Iconoir ships 1.
  • Both are MIT, so licensing is not a deciding factor here.

Which one should you choose?

Pick Phosphor Icons when

Design systems, products with strong visual hierarchy, and teams that want one library to cover every context. The weight range also solves the common problem of outline icons disappearing on coloured or photographic backgrounds.

Consider otherwise if: If you only need one weight, the six-weight structure is overhead you will not use — Lucide or Tabler are simpler. If you want duotone plus a premium aesthetic, compare Solar and Huge Icons.

Pick Iconoir when

Side projects, startups, and open-source tools that need breadth without a licensing conversation. Iconoir is a reliable default when you do not yet know which icons you will need.

Consider otherwise if: Lucide has stronger governance and a larger community; Tabler has roughly triple the icon count. Iconoir's advantage is that nothing is ever paywalled.

Coverage

Phosphor Icons contains 9,198 icons and Iconoir contains 2,020. Phosphor is built around a single idea: one icon family that works at every weight. Each of its 9,198 icons is available in six weights — Thin, Light, Regular, Bold, Fill, and Duotone — so you can express hierarchy, hover state, and emphasis without ever leaving the library.

Iconoir started as one designer's answer to a simple frustration: good icon libraries kept gating the useful icons behind a paid tier. The set is 2,020 icons on a 24×24 grid with a 1.5px stroke, and there is no premium version — every icon is free, forever.

Frequently asked questions

Which has more icons, Phosphor or Iconoir?

Phosphor Icons has 9,198 icons and Iconoir has 2,020. Phosphor Icons is larger by about 355%. Raw count is not the whole story though — a 20,000-icon set with many near-duplicate variants can be slower to search than a tightly edited 2,000-icon set.

Can I mix Phosphor and Iconoir in one interface?

You can, but it usually looks wrong. Each library draws to its own grid and stroke weight — Phosphor uses 24×24 and Iconoir uses 24×24 — so icons from both sit slightly differently next to each other. If you must mix them, keep each library to a distinct area of the interface rather than interleaving them in the same toolbar.

What licenses do Phosphor and Iconoir use?

Phosphor Icons is MIT: Commercial use, modification and redistribution with no attribution required. Iconoir is MIT: Commercial use, modification and redistribution with no attribution required. Neither requires payment, but attribution rules differ, so check before shipping in a product where credit is inconvenient.

Do Phosphor and Iconoir include filled and outline versions?

Phosphor Icons offers thin, light, regular, bold, fill and duotone; Iconoir offers outline only. If you need to express selected and unselected states with the same glyph, the library with more variants saves you from importing a second set.

Which is better for small sizes like 16px?

At 16px, stroke weight and counter size matter more than coverage. Phosphor draws on a 24×24 grid and Iconoir on 24×24. Libraries that redraw per size rather than scaling — such as Fluent UI — generally hold up best. The reliable test is to preview both at your actual render size, which you can do on any icon page on IconStash.
