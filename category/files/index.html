About Files icons

What this category covers

The files category collects icons for file, folder, archive and clipboard icons for document managers and upload flows. Because IconStash indexes 28 libraries side by side, a single search here returns the same concept drawn by many different design teams — which is the fastest way to find an icon that matches your product's existing visual language.
