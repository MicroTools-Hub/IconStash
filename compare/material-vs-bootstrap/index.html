Material vs Bootstrap

Material Design Icons and Bootstrap Icons are two of the most widely used open-source icon sets. Both are free, both ship framework packages, and both will look perfectly reasonable in a product UI — which is exactly why the choice is annoying. This page puts the two side by side using the actual artwork and the real numbers.

The short answer

  • Material Design Icons is the broader set: 14,001 icons against 2,090 in Bootstrap Icons — roughly 570% more coverage, which matters most if you build interfaces that need unusual glyphs.
  • Material Design Icons gives you more visual range: 5 variants per concept (outlined, rounded, sharp, two-tone and filled), where Bootstrap Icons ships 3.
  • Both are Apache 2.0, so licensing is not a deciding factor here.

Which one should you choose?

Pick Material Design Icons when

Products that follow Material Design, Android-adjacent apps, and any interface where recognition matters more than distinctiveness. If your users already use Gmail, Drive, or Android, these icons need no explanation.

Consider otherwise if: Google's newer Material Symbols supersedes this set with variable-font icons in a single file. For a less Google-flavoured look, Fluent UI and Carbon are the enterprise equivalents.

Pick Bootstrap Icons when

Bootstrap-based projects, admin templates, and compact interfaces where icons sit next to 14px text and need to hold their own at 16px.

Consider otherwise if: If you need strict visual consistency, the mixed fill and stroke treatment can look uneven next to Lucide or Feather. For a larger set with similar small-size optimisation, compare Octicons.

Coverage

Material Design Icons contains 14,001 icons and Bootstrap Icons contains 2,090. Material Design Icons is Google's official icon set, and it is the most widely deployed icon vocabulary on the web. The 14,001 icons follow the Material geometry rules — a 24×24 grid with 2px keypoint padding, straight edges softened by corner radii, and a deliberate, slightly geometric construction.

Bootstrap Icons is the official icon set for the Bootstrap framework, built by the Bootstrap team. The 2,090 icons are drawn on a 16×16 grid — tighter than the 24×24 used by most libraries — which makes them pair naturally with Bootstrap's default typography and compact control sizing.

Licensing

Material Design Icons is released under Apache 2.0. No attribution required, but carries an explicit patent grant and requires notice for modified files.

Bootstrap Icons is released under MIT. Commercial use, modification and redistribution with no attribution required.

Frequently asked questions

Which has more icons, Material or Bootstrap?

Material Design Icons has 14,001 icons and Bootstrap Icons has 2,090. Material Design Icons is larger by about 570%. Raw count is not the whole story though — a 20,000-icon set with many near-duplicate variants can be slower to search than a tightly edited 2,000-icon set.

Can I mix Material and Bootstrap in one interface?

You can, but it usually looks wrong. Each library draws to its own grid and stroke weight — Material uses 24×24 and Bootstrap uses 16×16 — so icons from both sit slightly differently next to each other. If you must mix them, keep each library to a distinct area of the interface rather than interleaving them in the same toolbar.

What licenses do Material and Bootstrap use?

Material Design Icons is Apache 2.0: No attribution required, but carries an explicit patent grant and requires notice for modified files. Bootstrap Icons is MIT: Commercial use, modification and redistribution with no attribution required. Neither requires payment, but attribution rules differ, so check before shipping in a product where credit is inconvenient.

Do Material and Bootstrap include filled and outline versions?

Material Design Icons offers outlined, rounded, sharp, two-tone and filled; Bootstrap Icons offers outline, filled and more. If you need to express selected and unselected states with the same glyph, the library with more variants saves you from importing a second set.

Which is better for small sizes like 16px?

At 16px, stroke weight and counter size matter more than coverage. Material draws on a 24×24 grid and Bootstrap on 16×16. Libraries that redraw per size rather than scaling — such as Fluent UI — generally hold up best. The reliable test is to preview both at your actual render size, which you can do on any icon page on IconStash.
