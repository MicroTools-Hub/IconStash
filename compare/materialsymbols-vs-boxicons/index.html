Material Symbols vs Boxicons

Material Symbols and Boxicons are two of the most widely used open-source icon sets. Both are free, both ship framework packages, and both will look perfectly reasonable in a product UI — which is exactly why the choice is annoying. This page puts the two side by side using the actual artwork and the real numbers.

The short answer

  • Material Symbols is the broader set: 18,547 icons against 3,389 in Boxicons — roughly 447% more coverage, which matters most if you build interfaces that need unusual glyphs.
  • Material Symbols gives you more visual range: 4 variants per concept (variable weight, fill, grade and optical size axes), where Boxicons ships 3.
  • Both are Apache 2.0, so licensing is not a deciding factor here.

Which one should you choose?

Pick Material Symbols when

Products that want continuous control over icon weight and fill state, and teams that would rather ship one font file than manage five icon sets.

Consider otherwise if: If you need individually imported SVG components with tree-shaking, the older Material Icons set or Lucide is a better fit — a variable font loads all 18,547 glyphs even if you use thirty of them.

Pick Boxicons when

Websites and apps that need UI icons and brand logos from one package — particularly portfolios, link-in-bio pages, tech stack sections, and footers.

Consider otherwise if: For pure brand logos with a cleaner license, Simple Icons is CC0 and has 3,714 marks. For UI icons alone, Remix Icon and Tabler are more consistent.

Coverage

Material Symbols contains 18,547 icons and Boxicons contains 3,389. Material Symbols is Google's current icon format and the successor to Material Icons. It is built on variable font technology: all 18,547 icons live in a single font file, and four axes — Weight, Fill, Grade, and Optical Size — can be adjusted continuously rather than by swapping between five static themes.

Boxicons is a long-running free icon pack by Atisa, with 3,389 icons across three families: Regular (outline), Solid (filled), and Logos. The logo set is a significant part of the appeal — hundreds of brand marks maintained alongside the UI icons.

Licensing

Material Symbols is released under Apache 2.0. No attribution required, but carries an explicit patent grant and requires notice for modified files.

Boxicons is released under MIT. Commercial use, modification and redistribution with no attribution required.

Frequently asked questions

Is Material Symbols or Boxicons better for React projects?

Both have first-party React packages: @material-symbols/svg-400 and boxicons. Material Symbols has the larger catalogue, so for a React app the practical difference is coverage and visual style rather than integration effort. Both tree-shake, so bundle size tracks the number of icons you import, not the size of the library.

Which has more icons, Material Symbols or Boxicons?

Material Symbols has 18,547 icons and Boxicons has 3,389. Material Symbols is larger by about 447%. Raw count is not the whole story though — a 20,000-icon set with many near-duplicate variants can be slower to search than a tightly edited 2,000-icon set.

Can I mix Material Symbols and Boxicons in one interface?

You can, but it usually looks wrong. Each library draws to its own grid and stroke weight — Material Symbols uses 24×24 and Boxicons uses 24×24 — so icons from both sit slightly differently next to each other. If you must mix them, keep each library to a distinct area of the interface rather than interleaving them in the same toolbar.

What licenses do Material Symbols and Boxicons use?

Material Symbols is Apache 2.0: No attribution required, but carries an explicit patent grant and requires notice for modified files. Boxicons is MIT: Commercial use, modification and redistribution with no attribution required. Neither requires payment, but attribution rules differ, so check before shipping in a product where credit is inconvenient.

Do Material Symbols and Boxicons include filled and outline versions?

Material Symbols offers variable weight, fill, grade and optical size axes; Boxicons offers regular, solid and logos. If you need to express selected and unselected states with the same glyph, the library with more variants saves you from importing a second set.

Which is better for small sizes like 16px?

At 16px, stroke weight and counter size matter more than coverage. Material Symbols draws on a 24×24 grid and Boxicons on 24×24. Libraries that redraw per size rather than scaling — such as Fluent UI — generally hold up best. The reliable test is to preview both at your actual render size, which you can do on any icon page on IconStash.
