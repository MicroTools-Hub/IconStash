Phosphor vs Boxicons

Phosphor Icons and Boxicons are two of the most widely used open-source icon sets. Both are free, both ship framework packages, and both will look perfectly reasonable in a product UI — which is exactly why the choice is annoying. This page puts the two side by side using the actual artwork and the real numbers.

The short answer

  • Phosphor Icons is the broader set: 9,198 icons against 3,389 in Boxicons — roughly 171% more coverage, which matters most if you build interfaces that need unusual glyphs.
  • Phosphor Icons gives you more visual range: 6 variants per concept (thin, light, regular, bold, fill and duotone), where Boxicons ships 3.
  • Both are MIT, so licensing is not a deciding factor here.

Which one should you choose?

Pick Phosphor Icons when

Design systems, products with strong visual hierarchy, and teams that want one library to cover every context. The weight range also solves the common problem of outline icons disappearing on coloured or photographic backgrounds.

Consider otherwise if: If you only need one weight, the six-weight structure is overhead you will not use — Lucide or Tabler are simpler. If you want duotone plus a premium aesthetic, compare Solar and Huge Icons.

Pick Boxicons when

Websites and apps that need UI icons and brand logos from one package — particularly portfolios, link-in-bio pages, tech stack sections, and footers.

Consider otherwise if: For pure brand logos with a cleaner license, Simple Icons is CC0 and has 3,714 marks. For UI icons alone, Remix Icon and Tabler are more consistent.

Coverage

Phosphor Icons contains 9,198 icons and Boxicons contains 3,389. Phosphor is built around a single idea: one icon family that works at every weight. Each of its 9,198 icons is available in six weights — Thin, Light, Regular, Bold, Fill, and Duotone — so you can express hierarchy, hover state, and emphasis without ever leaving the library.

Boxicons is a long-running free icon pack by Atisa, with 3,389 icons across three families: Regular (outline), Solid (filled), and Logos. The logo set is a significant part of the appeal — hundreds of brand marks maintained alongside the UI icons.

Frequently asked questions

Is Phosphor or Boxicons better for React projects?

Both have first-party React packages: phosphor-react and boxicons. Phosphor has the larger catalogue, so for a React app the practical difference is coverage and visual style rather than integration effort. Both tree-shake, so bundle size tracks the number of icons you import, not the size of the library.

Which has more icons, Phosphor or Boxicons?

Phosphor Icons has 9,198 icons and Boxicons has 3,389. Phosphor Icons is larger by about 171%. Raw count is not the whole story though — a 20,000-icon set with many near-duplicate variants can be slower to search than a tightly edited 2,000-icon set.

Can I mix Phosphor and Boxicons in one interface?

You can, but it usually looks wrong. Each library draws to its own grid and stroke weight — Phosphor uses 24×24 and Boxicons uses 24×24 — so icons from both sit slightly differently next to each other. If you must mix them, keep each library to a distinct area of the interface rather than interleaving them in the same toolbar.

What licenses do Phosphor and Boxicons use?

Phosphor Icons is MIT: Commercial use, modification and redistribution with no attribution required. Boxicons is MIT: Commercial use, modification and redistribution with no attribution required. Neither requires payment, but attribution rules differ, so check before shipping in a product where credit is inconvenient.

Do Phosphor and Boxicons include filled and outline versions?

Phosphor Icons offers thin, light, regular, bold, fill and duotone; Boxicons offers regular, solid and logos. If you need to express selected and unselected states with the same glyph, the library with more variants saves you from importing a second set.

Which is better for small sizes like 16px?

At 16px, stroke weight and counter size matter more than coverage. Phosphor draws on a 24×24 grid and Boxicons on 24×24. Libraries that redraw per size rather than scaling — such as Fluent UI — generally hold up best. The reliable test is to preview both at your actual render size, which you can do on any icon page on IconStash.
