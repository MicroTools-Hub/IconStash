Design & UX integration

Aesthetic characteristics

Ionicons ships Earth in Outline, Filled and Sharp variants. Sharp drops the rounded corners for a more angular look, which makes the set unusually flexible — the same icon can read as approachable or as technical depending on which variant you pick.

UX best practices

Weather icons are scanned rather than read, so the Earth icon must stay legible at small sizes and be consistent with the rest of the forecast set. The most common mistake is mixing outline and filled glyphs across one forecast row, which makes a single strip look like two different data sources.
