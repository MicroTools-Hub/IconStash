Remix vs Fluent UI

Remix Icon and Fluent UI Icons are two of the most widely used open-source icon sets. Both are free, both ship framework packages, and both will look perfectly reasonable in a product UI — which is exactly why the choice is annoying. This page puts the two side by side using the actual artwork and the real numbers.

The short answer

  • Fluent UI Icons is the broader set: 20,170 icons against 3,244 in Remix Icon — roughly 522% more coverage, which matters most if you build interfaces that need unusual glyphs.
  • Remix Icon gives you more visual range: 2 variants per concept (line and fill), where Fluent UI Icons ships 2.
  • Both are Apache 2.0, so licensing is not a deciding factor here.

Which one should you choose?

Pick Remix Icon when

Products that already have a strong visual identity and need icons that adapt to it. The lighter stroke and neutral construction make Remix easy to pair with custom typography and colour systems.

Consider otherwise if: If you want a heavier, more characterful outline, Lucide and Tabler read bolder. For more than two variants per icon, Phosphor and Solar go further.

Pick Fluent UI Icons when

Enterprise applications, Microsoft 365 integrations, and products that already follow Fluent or need extremely broad coverage. The count alone means you will rarely need to look elsewhere.

Consider otherwise if: The size is also a drawback — with 20,170 icons, maintaining visual consistency across a product takes more discipline. Lucide and Heroicons are far easier to keep coherent.

Coverage

Remix Icon contains 3,244 icons and Fluent UI Icons contains 20,170. Remix Icon is a neutral-style system icon set maintained by Remix Design, organised across 25 categories. Its 3,244 icons are drawn on a 24×24 grid with a 1.5px stroke — noticeably lighter than the 2px default of Lucide or Tabler, which gives the set a more refined, technical feel.

Fluent UI Icons is Microsoft's icon library for the Fluent Design System, and at 20,170 icons it is the largest set indexed on IconStash. The icons are drawn across multiple sizes from 12px to 48px and in Regular and Filled styles.

Licensing

Remix Icon is released under Apache 2.0. No attribution required, but carries an explicit patent grant and requires notice for modified files.

Fluent UI Icons is released under MIT. Commercial use, modification and redistribution with no attribution required.

Frequently asked questions

Which has more icons, Remix or Fluent UI?

Remix Icon has 3,244 icons and Fluent UI Icons has 20,170. Fluent UI Icons is larger by about 522%. Raw count is not the whole story though — a 20,000-icon set with many near-duplicate variants can be slower to search than a tightly edited 2,000-icon set.

Can I mix Remix and Fluent UI in one interface?

You can, but it usually looks wrong. Each library draws to its own grid and stroke weight — Remix uses 24×24 and Fluent UI uses 12–48 — so icons from both sit slightly differently next to each other. If you must mix them, keep each library to a distinct area of the interface rather than interleaving them in the same toolbar.

What licenses do Remix and Fluent UI use?

Remix Icon is Apache 2.0: No attribution required, but carries an explicit patent grant and requires notice for modified files. Fluent UI Icons is MIT: Commercial use, modification and redistribution with no attribution required. Neither requires payment, but attribution rules differ, so check before shipping in a product where credit is inconvenient.

Do Remix and Fluent UI include filled and outline versions?

Remix Icon offers line and fill; Fluent UI Icons offers regular and filled. If you need to express selected and unselected states with the same glyph, the library with more variants saves you from importing a second set.

Which is better for small sizes like 16px?

At 16px, stroke weight and counter size matter more than coverage. Remix draws on a 24×24 grid and Fluent UI on 12–48. Libraries that redraw per size rather than scaling — such as Fluent UI — generally hold up best. The reliable test is to preview both at your actual render size, which you can do on any icon page on IconStash.
