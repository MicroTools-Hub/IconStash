About bold icons

What this style means

Bold icons are heavy-weight icons with thickened strokes or filled mass for maximum emphasis. IconStash classifies icons by style across all 28 indexed libraries, so you can hold the weight constant and compare how different design teams solve the same icon.

When to use them. Bold icons work at large sizes and in marketing layouts where a regular-weight icon looks weak. They lose definition below about 20px, so avoid them in compact controls.

Every icon below links to a page with the full SVG source, a live preview you can recolour and resize, PNG export at six sizes, and a ready-to-paste React snippet.
