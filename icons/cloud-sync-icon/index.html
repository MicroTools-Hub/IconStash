Choosing the right cloud sync icon

Match the icon to the interface

A cloud sync icon has to read instantly at whatever size your interface uses. Below 20px, prefer outline artwork with a consistent stroke weight — heavy filled glyphs turn into blobs. For navigation bars and empty states above 32px, filled or duotone versions carry more visual weight and scan better.

Keep stroke weight consistent across every icon in a view. Mixing a 1.5px Lucide glyph with a 2px Tabler glyph in the same toolbar is the most common reason icon sets look unprofessional.

Accessibility

Decorative icons need aria-hidden="true" so screen readers skip them. If the cloud sync icon is the only thing labelling a control — an icon-only button, for example — give the button an aria-label such as "Cloud Sync" and leave the SVG itself hidden.

Never rely on the icon alone to convey state. Pair it with a tooltip or visible text wherever the meaning is not already obvious from context.
